# Roadmap

## Paired execution foundation

Implemented:

- App Server stdio adapter;
- model, effort, catalog, and quota discovery;
- static, Auto, and paired CLI modes;
- dirty-state worktree replication;
- blind command verification;
- cost and utility reports;
- local telemetry;
- STATIC/AUTO/TWIN/ABSTAIN meta-controller;
- empirical-Bayes uplift bounds;
- protocol mock and end-to-end tests.

## Multi-axis control and direct invocation

Implemented:

- first-class speed/service-tier routing;
- runtime `serviceTiers` discovery;
- separate capability, effort, speed, and topology economics;
- premium-speed urgency and live-quota gates;
- speed-aware certificates and cost accounting;
- speed-only intervention handling in the meta-controller;
- Codex plugin manifest and `counterlane` skill;
- local stdio MCP and session-aware Streamable HTTP MCP with optional static bearer authentication;
- direct `@Counterlane` invocation in ChatGPT/Work and `$counterlane` invocation in Codex;
- local personal-marketplace installer;
- automated unit, integration, protocol, cancellation, and isolation coverage.

## Measurement hardening

- SQLite experiment store;
- randomized A/B labels and execution order;
- repeat scheduler and paired bootstrap reports;
- hidden verifier service interface;
- environment manifest and record/replay;
- protected verifier paths;
- explicit contamination labels;
- stronger cancellation propagation;
- time-to-first-useful-action telemetry;
- service-tier availability and reliability telemetry.

## Temporal routing

- read-only scout phase;
- evidence capsules on escalation;
- route checkpoints between reconnaissance, planning, implementation, and validation;
- hysteresis and context/cache-switch penalties;
- phase-specific model × effort × speed value estimates;
- opportunistic speed downgrade after the interactive bottleneck passes.

## Learned self-falsifying controller

- calibrated conditional uplift models;
- doubly robust or randomized-policy estimators;
- per-repository, organization, and user hierarchical adaptation;
- drift detection and policy rollback;
- confidence-aware deployment gates;
- learned quota shadow price and future-workload forecast.

## Verification-first compute allocation

- mutation plug-in protocol;
- failure atlas;
- route-conditioned verifier adequacy;
- hard bad-escape constraints;
- independent reviewer routes;
- verification strengthening before model escalation.

## Ultra research

- workstream decomposition contracts;
- verifier separability score;
- Max-versus-Ultra paired trials;
- duplicate-work and merge-conflict metrics;
- Ultra waste-rate controller;
- safe bounded concurrency;
- topology-aware speed allocation per worker.

## Product release criteria

- stable compatibility across supported Codex builds;
- documented Work/CLI/IDE integration behavior;
- reproducible held-out evaluation;
- calibrated route probabilities;
- selective twin overhead below declared threshold;
- external security review;
- no unresolved high-severity safety findings.
